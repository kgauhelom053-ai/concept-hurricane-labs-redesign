# Hurricane Labs Managed SOC page: concept redesign + audit

A mobile-first concept redesign of the Managed SOC service page, with SEO basics in place (unique title and description, one H1, ordered headings, alt text, JSON-LD for Organization, Service, BreadcrumbList and FAQPage, and a 1200×630 share image), plus a short mobile and SEO audit of the live site (`audit.html`).

**Concept demo by Kgauhelo Mokoena, not affiliated with or commissioned by Hurricane Labs.** Copy and figures come from Hurricane Labs' public website. No logo files are used.
